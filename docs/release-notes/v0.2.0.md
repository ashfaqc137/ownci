This release fixes commands and hints that sent you in circles, hardens how tokens and labels are handled, and adds progress output to `setup`.

## Install

```bash
curl -fsSL https://sparshlabs.com/ownci/install.sh | sh
```

The script checks the archive against `SHA256SUMS` and installs `ownci` into `~/.local/bin`.
Set `OWNCI_VERSION=v0.2.0` to pin this version. The archives carry GitHub build-provenance
attestations: `gh attestation verify ownci_v0.2.0_linux_<arch>.tar.gz --repo ashfaqc137/ownci`.

To upgrade, install the new binary, then run `ownci stop` and `ownci start`. The runner registration is kept.

## Changed behaviour

- **`start` re-checks the repository's visibility** when a GitHub token is available. It refuses to
  run if the repository has become public since setup, unless setup was run with `--allow-public-repo`. `status --remote` warns about it too.
- **Hosted-runner labels are refused** by `setup --labels`: `ubuntu-*`, `windows-*` and `macos-*`.
  A `runs-on: ubuntu-latest` can no longer reach your machine through a label you added.
- **An invalid `--repo` or `--name` exits with code 2** (a usage error) instead of 1.
  `setup` also rejects stray arguments.
- **The registration token is passed to the runner through its environment**
  (`ACTIONS_RUNNER_INPUT_TOKEN`), not its command line, where other users on the machine could read it.
  `GITHUB_TOKEN` and `GH_TOKEN` are removed from the runner's environment.

## Fixed

- **Hints that failed:** about ten error hints said `ownci setup --force`, which always failed
  with "--repo is required". `setup` now uses the configured repository when `--repo` is left out.
- **`setup --force` now replaces an outdated runner.** If the runner could not update itself
  (`version_deprecated`), the advice to run `setup --force` used to loop forever. Now
  `setup --force` replaces any runner older than the one OwnCI pins. If the download fails,
  the registration is kept.
- **`start` no longer kills unrelated processes.** The cleanup of leftover runner processes
  killed any process that had a runner file among its first two arguments, such as an
  editor with `.env` open. It now matches only runner binaries and runner scripts.
- **Ctrl-C** during `start`'s preparation is a clean stop.
- **`stop`** waits 75 s by default in container-runner mode.
- **GitHub's secondary rate limits** are reported as rate limits.

## Hardening

- **The cleanup hook:**
  - records a failure when the work directory is not the one it expects;
  - removes a symlinked `_temp` or `_PipelineMapping`;
  - pulls its digest-pinned image if it is missing.
- **Host mode:**
  - refuses a data directory containing `:` or `,`;
  - setup lists the Docker socket among the isolation notes.

## Improved

- **`setup` shows progress.** On a terminal:
  - a live line for the 217 MB runner download (percent, MB, speed);
  - a spinner for extracting, registering, installing the isolation settings and pulling the image.

  Piped output gets plain progress lines instead.
- **install.sh:**
  - prints how to add the install directory to `PATH` for good, not just for the current shell;
  - accepts `OWNCI_VERSION=latest`.
- **Docs and website:**
  - The README, `docs/` and the website now match the code.
  - New section: [Let only maintainers decide where jobs run](https://sparshlabs.com/ownci/docs/workflows/#maintainer-control).
  - Team labels are now `dev-<username>`.
